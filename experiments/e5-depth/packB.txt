# WIRING PACK v2.1 - generator-data form
# 'motif NAME(slots): template' defines a wiring shape; '$slot' substitutes fills.
# 'inst NAME(fills)' instantiates the template. An indented '+ line' is a DELTA: add it
# verbatim after expansion. 'impl I -> C' declares C as the implementation of interface I.
# A fill of '-' means the corresponding line is OMITTED from the expansion (e.g. entity=-
# and action=- mean the unit has NO anno line). Constants.* fills are literal values.
# Non-motif units appear explicitly (unit/dep/edge lines). Expansion of every inst
# reproduces the explicit form exactly.

motif CommandHandler(H, S, f, m, entity, action):
  unit $H
  anno $H @CommandType entity=$entity action=$action
  dep $H.$f: $S
  edge $H -> $S#$m
